# TimeLeapMemo-RS

タイムリープ・メモは、時間の流れを可視化し、過去や未来を自由に行き来しながら「思考の軌跡」を残すためのドローイング・メモアプリです。

## 主な機能
- **仮想時間システム**: 書いた瞬間の時間を記録。再生・シークで描画過程を再現。
- **マルチバース・パド (Chaos Pad)**: 全ての時間軸を一度に俯瞰。
- **インプレッション・タグ**: 重要な瞬間にタグを付け、瞬時にジャンプ。
- **オニオン・スキン**: 時間移動中に「未来」の線を透かして表示。
- **ヒストリカル・イレイザー**: 消しゴムで消した線も、その時間に戻れば再出現。

## 操作方法

### ツール
- **[1]** または **[E]**: ペン / 消しゴム の切り替え
- **[F]** または **[F11]**: フルスクリーン切り替え

### タイムトラベル・再生
- **[SPACE]** (長押し): マルチバース・パドを表示。マウス左右で時間を、上下で世界線を選択。
- **[B]** (長押し): タイム・スクラビング（全体を素早くシーク）
- **[3]** または **[N]**: 「現在 (NOW)」へジャンプ
- **[PLAY/PAUSE] ボタン**: 時間を一定速度で進める/止める

### タグ (インプレッション・タグ)
- **[T]** または **[5]**: 現在位置にタグを追加
- **[4]** または **[←]**: 前のタグへジャンプ
- **[6]** または **[→]**: 次のタグへジャンプ
- **検索バー**: タグ名でフィルタリング。エンターで描画画面にフォーカスが戻ります。

## データについて
- **data.bin**: メモ内容（ストローク、タグ）が保存されています。
- **settings.json**: ウィンドウサイズなどの設定が保存されています。
- リリース版には初期状態でからっぽの `data.bin` が含まれています。

## 動作環境
