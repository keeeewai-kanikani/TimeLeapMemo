# TimeLeapMemo-RS 技術仕様書

## 開発スタック
- **言語**: Rust
- **GUIフレームワーク**: Slint (SVGベース描画)
- **データ永続化**: Bincode (バイナリシリアライズ)
- **日付処理**: chrono crate

## コア・アーキテクチャ
1. **仮想時間 (Virtual Time)**:
   - 全ての描画データ（Stroke）は `virtual_time_created` を持ちます。
   - `std::time::Instant` を用いた **Delta Time 方式** により、低スペック環境でも再生速度が一定に保たれます。

2. **描画最適化**:
   - **Path Caching**: ストロークごとのSVGパスをメモリ上にキャッシュし、変更時のみ再生成。
   - **Quadratic Bezier**: 頂点間をベジェ曲線で近似することで、少ない頂点数で滑らかな曲線を実現。
   - **Vertex Limit**: 1ストロークあたり最大2000頂点に制限。

3. **マルチバース・レンダリング**:
   - すべての時間軸の密度を計算し、波形（Waveform）として可視化。
   - リアルタイムでの密度サンプリングとSlintによる動的描画。

4. **インプレッション・タグ**:
   - `ImpressionTag` 構造体による管理。
   - 仮想時間に基づく最短距離の探索アルゴリズムによるナビゲーション。

## ファイル構造
- `src/main.rs`: エントリポイント、タイマーループ、イベントハンドラ。
- `src/logic/`: ストローク、時間、タグ、世界線管理のコアロジック。
- `src/storage/`: バイナリおよびJSON形式での永続化処理。
- `ui/main_window.slint`: 独自UIコンポーネントとタイムライン描画。
